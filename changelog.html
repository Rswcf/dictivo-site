Changelog

What shipped, when, and what changed for the people using Dictivo every day.

v0.2.0 · Public beta · 2026-05-13

Onboarding tiers and history

  • Onboarding now matches the local engine tier to detected hardware on first launch.
  • History view keeps recent dictations reachable for review and reuse.
  • Dedicated privacy and local-engine settings panes.
  • Companion overlay during dictation for hands-on transcript visibility.
  • Signed and notarized macOS DMG; signed Windows EXE and MSI.
  • Installers served from downloads.dictivo.app via Cloudflare R2.

v0.1.0 · Private alpha

Initial dictation surface

  • Local-first dictation engine with the on-device speech pipeline.
  • Active transcript surface with visible recording state.
  • Hotkey scaffolding and a local user dictionary.
  • macOS and Windows builds from the same workspace.
