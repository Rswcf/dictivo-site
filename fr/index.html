Confidentialité d'abord

Vos mots privés restent sur votre Mac.

Dictivo commence en local, parce que la dictée devrait être privée par défaut. Cloud Fast est explicite, car il change l'endroit où l'audio est traité.

Mode local

Le chemin quotidien pour le travail privé, les notes sensibles, les échanges clients et les brouillons personnels.

  • L'audio du micro reste sur cet appareil
  • Transcriptions, historique, dictionnaire et extraits restent locaux
  • Fonctionne sans compte de transcription cloud
  • L'offre gratuite inclut le petit modèle local
  • Des modèles locaux plus puissants sont disponibles avec l'achat
Mode Cloud Fast

Un chemin rapide séparé pour les enregistrements peu sensibles quand l'attente casse le flux.

  • Ne s'exécute que si vous sélectionnez Cloud Fast
  • Téléverse l'enregistrement choisi pour une transcription plus rapide
  • Conçu pour les enregistrements peu sensibles
  • Le mode local reste disponible quand la confidentialité prime
  • Utilisez Local dès que l'audio est sensible.

Flux

Le flux reste volontairement simple.

Dictivo est conçu pour transformer rapidement vos idées en texte dans l'app où vous travaillez.

  1. 01 Télécharger pour Mac

    Commencez avec le modèle local gratuit. Aucun compte cloud n'est requis en mode Local.

  2. 02 Appuyer sur le raccourci

    Parlez depuis n'importe quelle app, arrêtez l'enregistrement et récupérez le texte.

FAQ

Questions avant le téléchargement.

Réponses courtes sur confidentialité, tarifs, Cloud Fast, langues et disponibilité.

01 Ma voix quitte-t-elle mon Mac? +

En mode Local, non. Audio et transcriptions restent sur l'appareil. En mode Cloud Fast, l'enregistrement choisi est envoyé pour une transcription plus rapide.

02 Qu'est-ce qui est gratuit? +

L'offre gratuite inclut le mode Local avec le petit modèle embarqué, le raccourci global et l'historique local.

03 Quand acheter Dictivo Local? +

Achetez Local si vous voulez des modèles embarqués plus forts, 12 mois de mises à jour et une dictée privée sans dépendre du cloud.

04 Qu'est-ce que Cloud Fast? +

Cloud Fast est le mode vitesse optionnel. Il téléverse certains enregistrements pour une transcription plus rapide.

05 Dois-je choisir la langue de dictée? +

Non. La langue de dictée est détectée automatiquement. Le menu de langue ne change que le site et l'interface.

06 Windows est-il disponible? +

Pas encore. Dictivo est disponible sur Mac maintenant, Windows arrive plus tard.
