隐私

你的私密内容留在 Mac 上。

Dictivo 默认从本地模式开始，因为大多数听写都应该默认私密。Cloud Fast 会被明确展示，因为它会改变音频处理位置。

本地模式

适合日常私密工作、敏感笔记、客户沟通和个人草稿。

  • 麦克风音频留在本设备
  • 转录文本、历史记录、词典和片段都保存在本地
  • 不需要云端转录账号
  • 免费版本包含轻量本地模型
  • 升级后可使用更大的本地模型
Cloud Fast 模式

为低敏感度录音准备的独立加速路径，避免等待打断工作流。

  • 只有选择 Cloud Fast 时才会运行
  • 上传所选录音以获得更快转录
  • 适合低敏感度录音
  • 隐私更重要时仍可随时使用本地模式
  • 音频敏感时请使用本地模式。

在安全页面查看完整的隐私边界。

Workflow

FAQ

下载前的常见问题。

关于隐私、价格、Cloud Fast、语言和可用性的简短回答。

01 我的声音会离开 Mac 吗？ +

本地模式不会。音频和转录文本都留在设备上。Cloud Fast 模式会上传你选择的录音以获得更快转录。

02 免费版本包含什么？ +

免费版本包含本地模式、轻量设备端模型、全局快捷键和本地历史记录。

03 什么时候应该购买 Dictivo Local？ +

如果你需要更强的本地模型、12 个月更新以及不依赖云端的私密听写，就适合购买 Local。

04 什么是 Cloud Fast？ +

Cloud Fast 是可选的加速模式，会上传所选录音以获得更快转录。

05 需要手动选择听写语言吗？ +

不需要。听写语言会自动检测。语言菜单只改变网站和界面显示语言。

06 Windows 可用吗？ +

还没有。Dictivo 目前支持 Mac，Windows 稍后推出。
