Privacidad primero

Tus palabras privadas se quedan en tu Mac.

Dictivo empieza en local porque el dictado debería ser privado por defecto. Cloud Fast es visible porque cambia dónde se procesa el audio.

Modo Local

La ruta diaria para trabajo privado, notas sensibles, conversaciones con clientes y borradores personales.

  • El audio del micrófono queda en este dispositivo
  • Transcripciones, historial, diccionario y fragmentos quedan locales
  • Funciona sin una cuenta de transcripción en la nube
  • El plan gratis incluye el modelo local pequeño
  • Los modelos locales más grandes están disponibles al actualizar
Modo Cloud Fast

Una ruta rápida separada para grabaciones poco sensibles cuando esperar rompe tu flujo.

  • Solo funciona cuando eliges Cloud Fast
  • Sube la grabación seleccionada para transcribir más rápido
  • Diseñado para grabaciones poco sensibles
  • Local sigue disponible cuando la privacidad importa más
  • Usa Local siempre que el audio sea sensible.

Flujo

El flujo es deliberadamente simple.

Dictivo está diseñado para pasar tus palabras a la app en la que trabajas justo cuando lo necesitas.

  1. 01 Descargar para Mac

    Empieza con el modelo local gratuito. No hace falta cuenta cloud para el modo Local.

  2. 02 Pulsa el atajo

    Habla desde cualquier app, detén la grabación y recupera la transcripción.

  3. 03 Cambia solo cuando haga falta

    Mantente en Local para lo privado. Usa Cloud Fast cuando la grabación no sea sensible y la velocidad importe.

FAQ

Preguntas antes de descargar.

Respuestas breves sobre privacidad, precios, Cloud Fast, idiomas y disponibilidad.

01 ¿Mi voz sale de mi Mac? +

En modo Local, no. Audio y transcripciones quedan en el dispositivo. En Cloud Fast, la grabación elegida se sube para transcribir más rápido.

02 ¿Qué incluye gratis? +

El plan gratuito incluye modo Local con el modelo pequeño, atajo global e historial local.

03 ¿Cuándo comprar Dictivo Local? +

Compra Local si quieres modelos en el dispositivo más potentes, 12 meses de actualizaciones y dictado privado sin depender de la nube.

04 ¿Qué es Cloud Fast? +

Cloud Fast es el modo rápido opcional. Sube grabaciones seleccionadas para transcripción más veloz.

05 ¿Elijo manualmente el idioma de dictado? +

No. El idioma de dictado se detecta automáticamente. El menú de idioma solo cambia el sitio y la interfaz.

06 ¿Está disponible Windows? +

Todavía no. Dictivo está disponible para Mac ahora y Windows llegará más adelante.
