개인정보

내 비공개 말은 Mac에 남습니다.

Dictivo는 기본적으로 로컬에서 시작합니다. Cloud Fast는 오디오 처리 위치가 바뀌기 때문에 명확히 표시됩니다.

Local 모드

개인 작업, 민감한 메모, 고객 대화, 개인 초안에 쓰는 기본 경로입니다.

  • 마이크 오디오는 이 기기에 남습니다
  • 전사문, 기록, 사전, 스니펫은 로컬에 보관됩니다
  • 클라우드 전사 계정 없이 작동합니다
  • 무료 버전에는 작은 로컬 모델이 포함됩니다
  • 업그레이드하면 더 큰 로컬 모델을 사용할 수 있습니다
Cloud Fast 모드

기다림이 흐름을 끊는 낮은 민감도의 녹음을 위한 별도 속도 경로입니다.

  • Cloud Fast를 선택할 때만 실행됩니다
  • 선택한 녹음을 업로드해 더 빠르게 전사합니다
  • 낮은 민감도의 녹음을 위해 설계되었습니다
  • 개인정보가 더 중요하면 언제든 Local을 사용할 수 있습니다
  • 오디오가 민감하면 Local을 사용하세요.

전체 개인정보 경계는 보안 페이지에서 확인하세요.

Cloud Fast

클라우드를 기본으로 만들지 않고 빠르게 전사합니다.

내용이 비공개라면 Local을 사용하고, 민감도가 낮고 속도가 중요할 때만 Cloud Fast를 사용합니다.

기본은 비공개.

  • 오디오는 컴퓨터에 남습니다
  • 전사문, 기록, 사전, 스니펫은 로컬에 보관됩니다
  • 고객 작업, 메모, 회의, 민감한 초안에 적합합니다

Workflow

워크플로는 의도적으로 단순합니다.

Dictivo는 머릿속의 말을 지금 사용하는 앱으로 바로 넣어야 하는 순간을 위해 설계되었습니다.

    개인 작업은 Local을 유지하세요. 민감도가 낮고 속도가 중요할 때 Cloud Fast를 사용하세요.

FAQ

다운로드 전 자주 묻는 질문.

개인정보, 가격, Cloud Fast, 언어, 사용 가능 여부에 대한 짧은 답변입니다.

01 내 목소리가 Mac 밖으로 나가나요? +

Local 모드에서는 아닙니다. 오디오와 전사문은 기기에 남습니다. Cloud Fast에서는 선택한 녹음이 더 빠른 전사를 위해 업로드됩니다.

02 무료에는 무엇이 포함되나요? +

무료 플랜에는 작은 온디바이스 모델을 쓰는 Local 모드, 전역 단축키, 로컬 기록이 포함됩니다.

03 언제 Dictivo Local을 구매해야 하나요? +

더 강력한 온디바이스 모델, 12개월 업데이트, 클라우드에 의존하지 않는 비공개 받아쓰기가 필요하면 Local이 적합합니다.

04 Cloud Fast란 무엇인가요? +

Cloud Fast는 선택형 속도 모드입니다. 선택한 녹음을 업로드해 더 빠르게 전사합니다.

05 받아쓰기 언어를 수동으로 선택하나요? +

아니요. 받아쓰기 언어는 자동 감지됩니다. 언어 메뉴는 사이트와 UI 표시 언어만 변경합니다.

06 Windows를 사용할 수 있나요? +

아직은 아닙니다. Dictivo는 현재 Mac에서 사용할 수 있고 Windows는 나중에 제공됩니다.
