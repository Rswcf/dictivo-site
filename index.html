Privacy boundary

Local is the product. Cloud Fast is the exception.

Dictivo should never make users guess where their voice went. The mode switch is the privacy boundary.

Local mode

The default path for private work, sensitive notes, client calls, and anything you do not want leaving the machine.

  • Microphone audio stays on this device
  • Transcripts, history, dictionary, and snippets stay local
  • Local polish runs after transcription without a server round-trip
  • Hardware-aware model setup chooses Fast, Medium, or Quality
  • Works even when you do not want a cloud transcription account
Cloud Fast mode

A separate speed path for recordings where fast turnaround matters more than keeping the audio strictly local.

  • Uploads the current recording to cloud transcription providers
  • Requires an active Cloud Fast subscription or license
  • Provider choice stays automatic and hidden in the app
  • Dictionary and snippets remain on the desktop and apply after text returns
  • Use Local whenever the audio is sensitive.

Mode decision

Choose by privacy need, not by settings anxiety.

Dictivo exposes exactly two modes because more choices would make the product harder to trust.

Local Default

For private work and daily drafting.

  • Audio remains on your computer
  • Transcription speed depends on your hardware
  • Fast / Medium / Quality tiers are calibrated locally
  • Works with history, dictionary, snippets, and Text cleanup
  • Best for client work, personal notes, meetings, and offline use
Cloud Fast Optional

For speed when the recording is not sensitive.

  • $6.99/month, separate from the Local license
  • 1,500 transcription minutes per month
  • Can be purchased standalone or alongside Local
  • Uploads selected recordings to cloud transcription providers
  • Provider routing is automatic and not exposed in the app

Local is paid like software. Cloud Fast is priced like a service.

Local dictation does not need a recurring cloud bill, so Dictivo Local is a one-time purchase. Cloud Fast has real provider cost, so it is a separate optional subscription.

FAQ

Answers before you install.

Current product behavior: Local first, Cloud Fast optional, no provider picker.

01 Does my voice ever leave my computer? +

In Local mode, no. Audio and transcripts stay on your device. In Cloud Fast mode, yes: the current recording is uploaded to cloud transcription providers for faster results. The app makes this a visible mode choice.

02 Why add Cloud Fast if Dictivo is privacy-first? +

Because not every recording has the same privacy requirement. Dictivo Local remains the default and the main product. Cloud Fast exists for low-sensitivity work where speed matters more than keeping the audio strictly local.

03 Can I buy Cloud Fast without buying Local? +

Yes. Cloud Fast is a separate $6.99/month subscription. You can use it standalone, or alongside a Dictivo Local license.

04 What does the Local license include? +

Dictivo Local is a $49 one-time purchase for the version you buy, plus 12 months of updates and new local models. After that, the version you have keeps working. Renewing for future updates is optional.

05 Do I choose the Cloud Fast provider or model? +

No. The app exposes one cloud mode: Cloud Fast. Routing and backup behavior are handled by Dictivo internally so the user does not need to manage model/provider choices.

06 Can I get a refund? +

Yes. Local purchases have a 14-day refund window. Email support@dictivo.app and we will handle it.
