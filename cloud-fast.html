Cloud Fast when speed matters. Local when privacy matters most.

Dictivo stays local by default. Cloud Fast is a separate subscription for the moments when local hardware latency gets in the way and you explicitly choose faster cloud transcription.

Upgrade to Cloud Fast Download Dictivo

Cloud Fast uploads the current recording to Dictivo's cloud transcription route. Local mode does not.

Default

Local still means local.

Local mode keeps audio, transcripts, history, dictionary entries, and snippets on this device. It remains the primary Dictivo product and the default recommendation for sensitive work.

Optional

Cloud Fast is a deliberate switch.

Cloud Fast uploads only the recording you choose to transcribe in cloud mode. Dictivo routes it through a Dictivo-owned Cloudflare proxy, then applies your local polish after text returns.

Mode boundary

Two modes, one obvious decision.

No provider picker, no model menu, no hidden automatic upload. Pick the privacy posture first.

Local Default

Best for private work

Activation flow

Checkout stays in the browser. Activation lands back in Dictivo.

  1. 01 Buy Cloud Fast

    Lemon Squeezy handles checkout, tax, receipt, subscription, and license email.

  2. 02 Open Dictivo

    Paste the Cloud Fast license key in Settings, or use the activation link from the email.

  3. 03 Choose Cloud Fast

    Switch from Local to Cloud Fast only when you accept cloud upload for that recording.
