Default

Local still means local.

Local mode keeps audio, transcripts, history, dictionary entries, and snippets on this device. It remains the primary Dictivo product and the default recommendation for sensitive work.

Optional

Cloud Fast is a deliberate switch.

Cloud Fast uploads only the recording you choose to transcribe in cloud mode. Dictivo handles entitlement, metering, and routing server-side, then applies local polish after text returns.

Mode boundary

Two modes, one obvious decision.

No provider picker, no model menu, no hidden automatic upload. Pick the privacy posture first.

Activation flow

  1. 01 Buy Cloud Fast

    Lemon Squeezy handles checkout, tax, receipt, subscription, and license email.

  2. 02 Open Dictivo

    Paste the Cloud Fast license key in Settings, or use the activation link from the email.

  3. 03 Choose Cloud Fast

    Switch from Local to Cloud Fast only when you accept cloud upload for that recording.
